# Surface: web map shell

Mode: Operate
Audience: 演示观众 / 预报会商
Job: 在一张铺满的天气海洋图上切换窗口与要素

## Direction contract

THESIS: 地图就是产品。拒绝三栏指挥大屏（左指标 / 中地球 / 右控件）。壳贴在图的边上，像 Ventusky 那样被找进来，而不是挡住图。

OWN-WORLD: 墨蓝底 `#0a1628`，强调青 `#5ac8e6`。控件是近实心深色条，不是大块玻璃卡。字用工作无衬线。签名动作：左侧点要素，右侧色阶立刻换成该场。

STORY: 打开即见场。选风/洋流/气温/降雨，读色阶，必要时搜地点或在区域上传 NC。

FIRST VIEWPORT: 全幅地图。左上 Logo+搜索+页链。左中竖要素轨。右中竖色阶（气温 50 在上 −40 在下）。底一条时次轴。右上只有缩放/投影小钮。区域场右下才出现双 CTA。

FORM: 用户钉死的品类标准（Ventusky 天气图）。seed: user-pinned-ventusky-canon。不跑 concept-seed 骰子。

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
